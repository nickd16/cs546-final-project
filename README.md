# cs546-final-project
City, Courts and Trails

# Steps
1. Have the archive unzipped
2. Have npm, nodejs, and mongodb installed
3. Run 'npm ci' from within the new folder to install the modules
4. Run 'npm run seed' to seed the mongodb database for the website
5. Run 'npm start' to launch the website
6. Use admin user with username: "admin" and password: "Courts1#" for admin user testing
7. Use normal user with username: "bob" and password: "Courts1#" for normal user testing
8. If more users are needed you can always make more with the register page
